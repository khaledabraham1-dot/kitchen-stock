# Python Kitchen Stock

A beginner-friendly Python project that simulates a simple kitchen inventory management system.

## Features

* Track available eggs, flour, and sugar.
* Display the total number of items in the kitchen.
* Check whether enough eggs are available.
* Use eggs and update the remaining stock.
* Simulate making a fried egg.

## Concepts Practiced

* Variables and arithmetic operations
* Functions and parameters
* Conditional statements (`if/else`)
* Return values
* Basic inventory management

## Technologies

* Python 3

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR_USERNAME/python-kitchen-stock.git
   ```

2. Navigate to the project directory:

   ```bash
   cd python-kitchen-stock
   ```

3. Run the program:

   ```bash
   python kitchen_stock.py
   ```

## Learning Objective

This project demonstrates fundamental Python programming concepts through a simple kitchen inventory simulation.
